# User Guide

## Getting Started

### 1. Sign Up
- Open app
- Click "Sign Up"
- Enter email and password
- Verify account

### 2. Add Notes
- Click "📚 My Notes"
- Create personal notes
- Or view preloaded notes from school/coaching

### 3. Take Tests
- Click "✍️ Tests"
- Choose MCQ or Written
- Complete test
- View AI feedback

### 4. Study Planner
- Click "📅 Study Planner"
- Enter exam details
- Set deadline
- App generates daily routine
- Set reminders

### 5. Enable Study Mode
- Click "🔒 Enable Study Mode"
- Device enters lockdown
- Only allowed apps: Classroom, WhatsApp, Google, Study apps
- Cannot exit until timer ends

### 6. Performance Analytics
- Click "📊 Performance Analytics"
- View test scores
- Track improvement
- Get personalized recommendations

## Features

### Forced Study Mode
- App stays in foreground
- Cannot close or minimize
- Other apps are blocked
- Alarm ignores volume settings

### AI Feedback
- Written test analysis using ML Kit
- Identifies mistakes
- Suggests improvements
- Personalized learning path

### Performance Tracking
- Real-time progress updates
- Teacher/Coaching dashboard
- Individual performance reports

## Tips for Success

✅ Set realistic study goals
✅ Complete daily tasks on time
✅ Review AI feedback
✅ Use preloaded notes
✅ Take regular tests
✅ Track your progress
